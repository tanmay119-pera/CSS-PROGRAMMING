PROBLEM 3.
Create a button & set its background color to :
> green using css stylesheet
> blue using <style>tag 
> pink using inline style 

solution - 
 
HTML FILE -

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="stylesheet" href="style.css">
    <style>
        button {
            background-color: blue; /* button element will have green text color */
        }
    </style>
</head>
<body>
    <button style="background-color: red">Click Me</button>
</body>
</html>

<!-- in this case it will take the color from the internal css file because it has more priority than external css file 
 and inline tag has much more priority than internal css file and external css file -->

CSS FILE - 

button {
    color : green; /* button element will have green text color */
}
/* in this case it will take the color from the internal css file because it has more priority than external css file */

<body>
    <nav class="navbar">
        <ul class="nav-list">
            <li><a href="#home">Home</a></li>
            <li><a href="#about">About Us</a></li>
            <li><a href="#services">Services</a></li>
            <li><a href="#contact">Contact Us</a></li>
        </ul>
    </nav>
</body>
</html>

CSS - FILE 

/* 
   Practice Set 6 - Q1: 
   Create a navbar with 4 options in the form of anchor tags inside list items.
   Now, use flexbox to place them all spaced equally in a single line.
*/

* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
    font-family: Arial, sans-serif;
}

.navbar {
    background-color: #333;
    padding: 15px 0;
}

/* Flexbox on the <ul> to space list items equally in a single line */
.nav-list {
    display: flex;
    justify-content: space-evenly; /* Equally spaced */
    align-items: center;
    list-style-type: none; /* Remove default bullet points */
}

.nav-list li a {
    color: white;
    text-decoration: none;
    font-size: 18px;
    padding: 8px 16px;
    transition: background-color 0.3s;
}

.nav-list li a:hover {
    background-color: #555;
    border-radius: 4px;
