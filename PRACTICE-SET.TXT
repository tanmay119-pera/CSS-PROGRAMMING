PROBLEM - 3 Which has higher priority - align-items or align-self?

HTML - FILE 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Practice Set 6 - Q3: align-items vs align-self</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="container">
        <h1>Which has higher priority: align-items or align-self?</h1>
        <p class="answer"><strong>Answer:</strong> <code>align-self</code> has a higher priority because it overrides the container's <code>align-items</code> property for that individual flex item.</p>

        <h2>Demonstration:</h2>
        <div class="flex-container">
            <div class="box default-item">align-items: flex-start</div>
            <div class="box custom-item-center">align-self: center (Overrides!)</div>
            <div class="box custom-item-end">align-self: flex-end (Overrides!)</div>
        </div>
    </div>
</body>
</html>

CSS - FILE 

/* 
   Practice Set 6 - Q3: 
   Question: Which has higher priority - align-items or align-self?

   Answer & Explanation:
   align-self has higher priority!
   - align-items is defined on the flex container to set the default alignment along the cross axis for ALL child items.
   - align-self is defined on an individual flex item to override the container's align-items value for that specific item.

{
    margin: 0;
    padding: 0;
    box-sizing: border-box;
    font-family: Arial, sans-serif;
}

body {
    padding: 30px;
    background-color: #f7f9fc;
}

.container {
    max-width: 800px;
    margin: 0 auto;
}

h1 {
    font-size: 22px;
    margin-bottom: 15px;
    color: #333;
}

.answer {
    font-size: 16px;
    margin-bottom: 25px;
    padding: 12px;
    background-color: #e8f5e9;
    border-left: 5px solid #4caf50;
}

/* Flex Container setting align-items: flex-start */
.flex-container {
    display: flex;
    height: 300px;
    background-color: #e0e0e0;
    border: 2px dashed #777;
    justify-content: space-around;
    align-items: flex-start; /* Container sets default alignment to top */
    padding: 10px;
}

.box {
    width: 180px;
    height: 80px;
    color: white;
    font-weight: bold;
    font-size: 13px;
    display: flex;
    justify-content: center;
    align-items: center;
    text-align: center;
    padding: 5px;
    border-radius: 6px;
}

/* Follows container align-items: flex-start */
.default-item {
    background-color: #1976d2;
}

/* Overrides with align-self: center */
.custom-item-center {
    background-color: #e65100;
    align-self: center; /* HIGHER PRIORITY than container's align-items */
}

/* Overrides with align-self: flex-end */
.custom-item-end {
    background-color: #388e3c;
    align-self: flex-end; /* HIGHER PRIORITY than container's align-items */
}
